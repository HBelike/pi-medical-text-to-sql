# 评测工作台与知识召回变更

- 目标：按 v3 为真实实验记录提供工作台，并增加可版本追踪的词法召回；不改 Pi 核心、不另建前端执行循环或评分算法。
- `apps/medical-query/web/evaluation.html/.css/.js` 提供实验、数据与知识、运行方案、对比、质量发布和产物存储六个入口，沿用既有黑白主题、原生表单与详情窗口。
- 工作台调用统一 `/api/eval` 接口，支持冻结创建、暂停/恢复/停止、派生重跑、逐题证据、独立重评、裁定、未知调用对账、质量决定、配置激活和删除影响核对；首页与历史页仅增加入口。
- 写入带幂等键和已有对象修订；网络失败后同请求保留原键。列表刷新采用请求取消与序号保护，编辑窗口或选择文本时暂停自动刷新；关闭浏览器不取消服务端任务。
- 评分、进度、容量、未知和发布状态来自控制服务；分轨分母、严重检查、阶段修复、首次归因、稳定性和实际用量均展示服务端冻结结果。局部阶段通过不代表整题通过，未知费用不按零处理；评分与任务历史分页，未知调用另外每页 25 条读取全账本，并区分仍占位与已人工释放，避免只看状态摘要前 100 条；完整产物可展开和导出。
- `src/knowledge-retrieval.ts` 提供 `retrieveMetrics`、`retrieveCatalog`、`retrieveDocuments`。L0 只裁候选目录，规则仍由既有 `L0Knowledge.select` 完整展开；facts 保留选表全部列与递归正向外键，仅在初始候选间做已确认关系的有界最短桥接，防止共享机构维度反向展开百表。
- 词法实现使用中文双元组、完整编号、别名、表列语义与代码字典，并以 IDF 降低共有说明噪声；收据保留输入版本、索引 hash、候选、入模、依赖边、字典投影、回退与字符预算。空召回回退全目录；超限错误携带完整收据；不伪装向量或混合检索。
- 文档在排序前按审核、撤回、数据源、医院、生效时间与出处过滤；文档仅作依据，不据此改写结构化口径。召回模块无外部依赖、不读取 gold，也不调用模型。
- `src/evaluation/store.ts` 增加持久 pending 命令、同键结果冲突检测、嵌套 savepoint、完整分页遍历与事件遍历；证据引用须真实存在，删除后的内容 hash 不自动复活，已有任务仍可在预留阈值以下落盘至真实剩余空间。
- `src/evaluation/http.ts` 在分页前传递评分、评分任务和激活过滤，规范页数与未知路由；`evaluate.ts`、`l0-evaluate.ts` 和两个 npm eval 脚本统一转到持久化控制 API，保留历史纯评分契约，停用旧独立付费执行入口。
- 调用链：工作台/CLI → 同源控制 API → 服务事务 → SQLite 状态与内容寻址产物；CLI 派发前输出幂等身份，断网后的重试可复用。严格三组对比协议在创建实验时登记，跨实验对比仍为探索用途。
- 验证：存储/路由/召回先前 15 项、CLI 与旧评分契约 32 项通过；召回 11 项通过，关系别名修复前临时 106 表包 40/40 道事实题保留必需表、15–30 表、150875–229088 字符且无需 LLM；别名修复后复测范围另记 `domain-relation-alias-change-summary.md`。工作台语法/Biome、当时全应用 TypeScript 通过；浏览器验证包括三组创建、暂停/恢复/取消、裁定重评→质量门→激活及导出；冻结版本隔离 HTTP 已完整验证 unknown 重启/幂等处置/额度释放→显式 fork 新身份→执行及评分，另验证产物引用核对/墓碑/删除标记；原始版本、记录和边界见 `evaluation-recovery-http-acceptance.md`，UI 对账与删除未标通过。最后未知分页已通过语法与独立配置 Biome；运行状态澄清文案已过语法，均尚未复跑视觉验证，详见 evaluation-workbench-test-report.md；不据此声称全部 A01–A25 或医院验收通过。
