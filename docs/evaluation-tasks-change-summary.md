# 新版评测中心变更总结

更新：2026-10-23。

1. 目标：参考用户七张原型实现任务列表→右侧详情抽屉→逐题过程展开及发起评测弹窗，同时保留 `/evaluation` 旧版。
2. 主要文件：`web/evaluation-tasks.html`、`.css`、`.js` 新增页面；`src/server.ts` 加固定路由；问数首页和历史页更新评测入口。
3. 评测服务增加轻量配置、列表筛选与分页、概览统计、逐题筛选与单题证据读取，页面使用真实冻结实验与最新有效评分。
4. 新建任务沿用现有题集/方案/实验接口和幂等键；上传沿用双 JSONL，模型只展示当前运行链路真实支持的决策与答案两种独立角色。
5. 设计理由、调用链、外部开源方案比较、依赖和后续边界见[设计记录](evaluation-tasks-design.md)；未引入新 UI 或评测框架依赖。
6. 验证：根目录 `npm run check` 通过（1481 文件、无需格式修复，含类型和浏览器冒烟）；定向评测 HTTP 测试 7/7、服务与运行统计测试通过。
7. 本机浏览器用既有 9 条实验验证列表、名称筛选、右侧抽屉、逐题 SQL/阶段证据、题集预览与黑白主题；保存了[深色详情预览](evidence/evaluation-tasks/dark-detail.png)。旧 `/evaluation` 页面及调用账本展开可用；操作详情改为按需读取，未触发真实模型评测。
8. 未完成边界：本机约 4GB 的 Durable 历史库在 512MB Node 堆限制下启动仍会 OOM；启动恢复和调度的全量扫描需要单独设计。本次保留旧版能力并优化其状态读取，默认启动堆实测可运行。
