# LLM 调用面板变更记录

更新：2026-10-15。目标是简化侧栏，并让每次真实调用的系统提示词、输入、输出可核对。

- 主要文件：`apps/medical-query/web/{app.js,styles.css,index.html}` 调整呈现；`src/model.ts`、`src/pipeline.ts` 及两份目标测试补齐输出记录。
- 精简布局：删除顶部“提示词/查询证据”按钮、左右面板标题和关闭头部、左栏用途说明与重复问题文案；保留问题选择器、调用名称、模型、状态及紧凑耗时/token 信息。
- 三段消息：每张卡展开 system、user、assistant；三个文本框均固定 200px、独立滚动并阻止向父栏传递滚动。system 保持原文，结构化输入/输出转换可读排版，“复制”使用精确收发文本。
- 调用链：`ModelGateway → model_calls[].output_text → 持久任务记录 → publicTurn → renderPrompts`；保存 assistant 正文及原始空白，不保存 reasoning 或网关错误正文，usage 摘要和业务 evidence 不重复保存正文。
- 异常语义：无效 JSON、输出截断和流中断保留已收到的文本，状态仍为失败；运行中尚无输出显示等待，历史缺字段明确提示，不从阶段产物或业务答案补造原文。
- 分支与边界：普通查询继续合并理解/匹配/计划，L0 两次调用按各自调用 ID 与阶段名显示；本次不改变调用顺序、提示词协议、4096/8192 预算、L0 数据或执行能力。
- 交互取舍：沿用原生 details、只读 textarea、现有主题及分栏，不新增依赖；把手统一承担开合，窄屏使用随抽屉移动的边缘把手，纳入 Tab 循环并在关闭后恢复焦点。
- 静态与目标测试：最终仓库根 `npm run check`、应用 check 和前端语法检查通过；`model.test.ts`、`pipeline.test.ts` 10 项全部通过，覆盖 SSE 原文、失败输出、预算与追问续跑隔离，仅使用本机替身和临时 SQLite。
- 浏览器验证：真实历史页面与独立合成样例检查通过，涵盖 L0 调用名称、完整/失败/缺失输出、长文本滚动、复制按钮反馈、桌面双栏 Escape 与 480×850 窄屏开关/焦点/无横向溢出。工具虚拟剪贴板未取得页面写入值，未将复制往返计为通过；效果图为 `apps/medical-query/.local/ui-checks/compact-llm-calls.png`。
