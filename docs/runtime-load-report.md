- 日期：2026-10-21T02:54:48.228Z；Apple M1 Pro / v24.16.0。全部使用临时SQLite、真实Pi Durable和生产ResourcePool；模型工作为30毫秒本机异步替身，没有提供商请求、生产数据库或在线端口访问。
- 5/10分别执行12波在线及三个评测实验到达；每波间隔至少20毫秒，实际间隔包含准入与状态读取耗时。每组先验证仅在线、仅评测均可借用全部5/10额度，再阻塞活动工作并填满评测队列，验证评测拒绝后在线仍能占用预留队列，最终全队列满后在线也明确拒绝。
- 活动任务与内层资源实际峰值分别为5/10；队列上限20/40，在线预留5/10。表内拒绝数是预期背压，未从提交分母删除；有限样本各实验在在线波次尚未停止时均有进展。完整启动顺序、每次到达/启动/完成及波次快照见[原始证据](runtime-load-evidence.json)。

- 此处测的是状态接口中runtime组件与操作读取，未测完整HTTP、真实大提示词分布或1万条Durable历史；不能用此前EvaluationStore索引分页结果替代。重开、样本RSS与每次操作在同机同进程观测，受缓存、GC和同期负载影响。源码冻结期间只记录线性扫描边界，未优化生产实现。
- 复现：应用目录设置PI_RUNTIME_LOAD_REPORT=1，执行node --import ../../scripts/issues/register.mjs --conditions=source --test test/runtime-load.test.ts；普通模式不覆盖报告。报告与JSON是本测试模块的变更及验证记录。
