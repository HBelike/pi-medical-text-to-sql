关系问题的证据：语义夹具明确登记两个 `rel.*`，来源为 `synthetic_sql_fk`；旧执行器从相同物理复合外键生成 `fk:<table>:<id>`，只额外接纳 `human_confirmed`，导致模型可见逻辑 ID 不能执行。修正应逐表逐列对核验别名与实际外键完全一致，不能直接把任意候选关系变成可执行关系。

DSL 缺口需通过受约束表达式、聚合和计划能力修复，并对机构复合键、JOIN 放大、NULL、单位、时间边界及零分母做独立验收；不能临时开放任意模型 SQL 或删除原题。当前报告不声称这些算子已完成。
