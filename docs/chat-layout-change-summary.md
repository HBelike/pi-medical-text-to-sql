# 聊天气泡与输入框变更记录

更新：2026-10-15。

- 目标：明确对话双方的左右位置，缩短底部输入框，改善圆角与留白。
- `apps/medical-query/web/app.js`：`renderTurn` 将问题与时间包入用户消息容器；问题、补充与助手回复增加可辨认的标签，沿用现有消息与结果渲染链。
- `apps/medical-query/web/styles.css`：用户问题和补充靠右、助手回复靠左，使用不同气泡底色与圆角；带结果表格的回答保留聊天行宽度，避免压缩列内容。
- 输入框与工作区共用列宽，始终位于中间聊天列，最大宽度 800px；侧栏开合和调整宽度时同步居中，收紧输入区间距并统一发送按钮尺寸。
- 窄屏改为单列并保留两侧留白，多行输入最高 140px 后内部滚动；复用现有主题、断点和侧栏控制，无新增依赖或后端改动，相关逻辑已补充中文注释。
- 验证：仓库根 `npm run check`、应用 `npm run check --workspace=@medical/pi-query` 与前端语法检查通过；浏览器核对 2560×1440、1440×1000、480×850 布局，未见横向溢出，验证侧栏收起、调宽及多行输入。
- 效果图保存在 `apps/medical-query/.local/ui-checks/chat-bubbles-composer.png`；本次未新增模型调用，未运行构建或全量测试，无遗留实现事项。
