# 问答历史页面变更记录

更新：2026-10-16。

- 目标：独立展示 ID、原始问题、答案输出、查询表、各环节模型、应答状态、时间和操作，首页顶栏增加“问答记录”。
- 设计：沿用问数页黑白及青绿主题，页面固定 `100dvh`；“Pi 智能问数 · 问答历史”共用一行标题，返回、刷新与主题切换统一右对齐，删除原来独立的标题说明区。顶栏与筛选、表格边缘对齐，窄屏操作缩为有完整名称的图标按钮；只有表格内部纵横滚动，分页固定底部。
- 调用链：`web/history.js` → `GET /api/history` → `QueryRuntime.list()` → `src/history.ts` 投影、筛选和分页；复用本地持久化记录，不重新执行问题或读取业务源。
- 数据口径：原始问题使用字面子串匹配，模型匹配任一实际调用；状态、数据源、时间共同过滤，筛选后回第一页。模型与环节来自历史调用和阶段关联；实际执行表与仅匹配表分别标注，L0 不显示为计算成功。
- 交互：支持完整详情及返回原会话，链接携带数据源、会话与回合标识；首页恢复并定位原问题，新对话清除旧定位，失效链接不会覆盖已保存会话。
- 单列调宽：八列表头均有独立拖柄，采用 Pointer Events 和像素列宽，总表宽随目标列变化，其他列保持不变；限制合理最小/最大宽度，支持左右方向键微调和双击复位，翻页及筛选保留本页已调列宽，刷新恢复默认值。
- 单元格阅读：数据列支持延迟悬停、聚焦或点击打开完整文本浮层；浮层内部滚动、允许选文、可按 Enter 进入及 Esc 关闭。列表最多预览两次模型调用，浮层保留全部环节和模型；读入浮层后移开鼠标不打断键盘阅读，换页、表格滚动或打开详情会关闭旧浮层。
- 技术取舍：调研 [Tabulator](https://github.com/tabulator-tables/tabulator) 与 [TanStack Table](https://github.com/TanStack/table)，两者均为 MIT 且有测试体系；前者需适配额外 UI/CSS，后者仍需自行渲染并接入状态层。本次固定八列采用原生表格，借鉴[筛选后回第一页的分页行为](https://www.tabulator.info/docs/6.x/page/)，无新增依赖。Firecrawl Developer Index 可用，后续抓取受额度限制，以官方仓库和文档补核；未运行候选库测试。
- 工程范围：新增 `web/history.html`、`web/history.css`、`web/history.js`、`src/history.ts` 及目标测试；扩展 `server.ts` 固定资源白名单。`package.json` 和 `biome.json` 同步扩大为 `web/*.js`，确保新增脚本实际进入检查，配置说明写在本文以保持 JSON 合法。
- 验证：本次顶栏改动后仓库根与应用 `npm run check` 均通过；未改后端、未新增模型调用、未运行构建或全量测试。前次历史模块目标测试 16/16 通过，并已核对真实接口 50 条记录、7 条组合筛选结果、无重复第二页及非法参数 400。
- 浏览器核对：本次确认 2560×1440 与 480×500 的标题和三个操作保持同排、按钮等高、分页可见且无整页溢出，刷新仍正确载入记录。此前已核对 1440×900、480×850，以及 50 条表内滚动、单列调宽、翻页保留列宽和完整内容浮层。新版截图见 `apps/medical-query/.local/ui-checks/query-history-header.png`。
- 边界：首版在已有运行文档上遍历筛选，分页限制网络返回量；当前每页最多 50 条，采用分页加容器滚动，未引入虚拟行或独立历史索引。列表含日常问答和明确标记的评测记录；本次仅修改 `web/history.html`、`web/history.css` 与本文，无新增依赖，保留原有按钮标识和调用链。
